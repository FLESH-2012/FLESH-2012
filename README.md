# Shahriyor — Portfolio

Shaxsiy portfolio: HTML, CSS, JavaScript va ichida ishlaydigan Snake o‘yini.

## Fayllar
- `index.html` — sahifa tuzilishi
- `style.css` — dizayn va mobil moslashuv
- `script.js` — Snake o‘yini va boshqaruv

## Ishga tushirish
`index.html` faylini brauzerda oching. Snake o‘yinini klaviaturadagi strelkalar yoki WASD tugmalari bilan, telefonda esa ekrandagi tugmalar bilan boshqaring.

## GitHub Pages orqali internetga chiqarish
1. GitHub’da yangi repository yarating.
2. Ushbu uchta faylni (`index.html`, `style.css`, `script.js`) repository’ning asosiy qismiga yuklang.
3. Repository → **Settings** → **Pages** bo‘limiga kiring.
4. **Deploy from a branch** ni tanlang.
5. Branch: `main`, folder: `/ (root)` qilib **Save** bosing.
6. GitHub Pages sayt manzilini yaratadi.
